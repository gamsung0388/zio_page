# 01. 제품·기능 명세

## 목적과 사용자
'ZIO HOME'은 지오의 공식 사용을 전제로 한 지오 **전용** 홈페이지 가칭이다. 방송 시청자(로그인 불필요)는 곡을 찾고 지오/관리자(로그인 필요)는 데이터를 관리한다. 공식 사이트라고 오인시키는 표현은 지오 동의 전 배포에 사용하지 않는다.

## 릴리스 범위
- **1차 필수**: 홈, 노래책자, 곡 검색/필터/정렬/상세, 관리자 로그인/로그아웃, CRUD, 공개/비공개, CSV 업·다운로드, 모바일.
- **2차 예정(이번에 개발 X)**: 방송 일정, 일정 관리, 주간 뷰.
- **보류**: 공지, 외부링크 관리, 갤러리/이미지 업로드, 실시간 방송/API, 노래 신청 접수/결제, 멀티 스트리머.

## 홈 `/`
브랜드 영역 `ZIO HOME`, 지오 소개(승인된 텍스트만), '노래책자 바로가기' CTA, 최근 공개곡 목록(최대 5건), 메뉴, 간단한 공백 상태 안내. 판다 모티브/산뜻한 녹색·아이보리, 과도한 애니메이션 금지. 초상·로고·아트는 권리 확인된 자료만 사용.

## 노래책자 `/songs`
- 검색: 곡명·가수(설명 검색은 옵션); 타이핑 디바운스(예 250~400ms)
- 필터: 숙련도 1~5, 연습 상태, 장르/언어(값 존재할 때), 공개곡만
- 정렬: 최신 등록, 제목, 가수, 숙련도 오름/내림, 풍 개수 오름/내림
- 페이징: 기본 20개, 최대 100개; 총 건수 및 현재 페이지
- 리스트: 제목, 가수, 숙련도, 연습 상태, 신청 필요 풍 개수
- 상세: Description, 장르, 언어 등; 풍은 결제/신청 버튼이 아니라 안내 문구

## 숙련도 (각각 독립값)
1 연습 필요 / 2 익숙하지 않음 / 3 보통 / 4 자신 있음 / 5 완곡 가능. 변경해도 연습 상태 자동 변경 없음.
연습 상태: `not_started` 미연습, `practicing` 연습 중, `completed` 연습 완료, `on_hold` 잠시 보류.

## 관리자 UI
추가 요청(2026-10-16): 로그인한 관리자의 추가 관리자 등록, 관리자 목록과 비밀번호 초기화, 본인 비밀번호 변경. 초기화 비밀번호는 `qwer1234!@#$`이며 이후 비밀번호 변경 전 관리 기능은 사용 불가. [상세](09_ADMIN_ACCOUNTS.md).

- `/admin`: 로그인 후 관리 메뉴. 관리자 관리 / 관리자 비밀번호 초기화 / 관리자 비밀번호 변경 / 노래 관리를 각각 선택한다.
- `/admin/users`: 관리자 목록·등록. 초기화 버튼은 표시하지 않는다.
- `/admin/password-reset`: 대상 계정 선택 후 확인을 거쳐 비밀번호 초기화.
- `/admin/password`: 본인 비밀번호 변경. 초기화 계정은 로그인 후 이 화면으로 이동.
- `/admin/login`: 계정 로그인. 공개 회원가입 없음.
- `/admin/songs`: 등록/수정/삭제/공개 전환, 필터 및 페이지네이션.
- 곡 필드: title(필수 1~200자), artist(필수 1~200자), description(0~5000자), genre(0~60), language(0~40), proficiency(1~5), practice_status(enum), balloon_cost(0 이상 정수), memo(관리자 전용 0~3000), is_public(boolean).
- 중복 제목 허용; 등록/수정 시 유효성 검사. 삭제 전 확인. 성공/실패 토스트.
- CSV 템플릿 다운로드, CSV 가져오기: 미리보기 + 행 검증 + 오류 위치 표시 + **기본값 추가만**(중복 기존 데이터 자동 덮어쓰기 금지), 최대 행·파일 크기 제한.
- CSV 내보내기: 관리자는 전체 노래 및 memo 포함 백업 가능, 공개 UI에는 CSV 백업 버튼 없음.

## UI/접근성
한국어 기본, 키보드 조작, 포커스 표시, 모바일 360px부터, 명확한 대비/상태 뱃지 및 대체 텍스트. 실제 로고/방송 이미지 제공 전에는 중립적인 판다 아이콘 또는 CSS 장식 사용.

## 완료 기준
1. 공개/비공개 분리와 권한 검증 확인.
2. 새로고침 후 DB 저장 유지. 곡 CRUD 전 과정 실제 작동.
3. 검색+필터+정렬+페이지 조합 정상.
4. 익명 사용자가 쓰기/비공개 조회/메모 조회 불가.
5. CSV 인코딩(UTF-8 BOM 포함), 잘못된 행, 중복 데이터 동작 확인.
6. Windows 로컬 개발, 빌드, D1 migration, 배포 절차 문서화.
7. 일정표 미구현 확인.
