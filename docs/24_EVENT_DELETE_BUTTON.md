# 24. 일정 삭제 버튼을 수정창에 표시

일정 달력의 막대나 목록의 수정을 누르면, 수정창 하단에 **이 일정 삭제** 버튼이 항상 보입니다. 백업 메뉴를 펼칠 필요가 없습니다. 삭제는 선택한 일정 전체 기간에 적용하며, 기존 확인 메시지·로그인·Origin·CSRF·저장 버전 검사는 유지합니다. 다른 일정과 주간 이미지 메모는 삭제하지 않습니다.

- PC에서는 하단 왼쪽에 삭제 버튼을 두고 저장 동작과 구분했습니다.
- 모바일에서는 고정된 하단 영역 안에 버튼 네 개를 배치합니다. 삭제와 저장을 색으로 구분하고, 44px 이상의 조작 높이를 유지합니다.
- 새 일정 등록창에는 삭제 버튼을 표시하지 않습니다.
- 삭제 중에는 버튼들을 잠그고 **삭제 중…**으로 표시합니다. 이때 저장 버튼에 저장 중이라는 잘못된 문구를 표시하지 않습니다.
- 백업·다시 불러오기는 기존 접힌 메뉴에 유지합니다. API와 D1 스키마·권한 구조는 변경하지 않았습니다.

## 검증

기존 브라우저 테스트 중 관련된 **4개 항목**을 실행합니다. 삭제 취소 시 요청이 나가지 않는지, 실제 삭제 후 같은 날의 다른 일정이 남는지, 동시 수정 충돌과 다시 불러오기가 유지되는지, 마지막 항목 삭제 후 목록 페이지가 보정되는지를 격리된 D1에서 확인합니다.

1920×1080, 1440×900, 768×1024, 390×844, 360×800에서 새 일정에는 삭제 버튼이 없고 수정창에는 보이는지 확인합니다. 수정창의 하단 버튼이 화면 안에 들어오고 가로로 넘치지 않는지 검증합니다. 운영 데이터에 시험용 삭제를 수행하지 않습니다. 기존 사용자 SQL 변경과 UI 참고 ZIP은 보존합니다.
