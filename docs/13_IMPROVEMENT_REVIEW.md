## R1. 세션 만료 시 초안 보호

일정 입력 뒤 저장 요청에 401을 반환시키면 /admin/login?expired=1로 즉시 이동합니다. 다시 로그인하고 같은 주를 열었을 때 입력 내용은 비어 있었습니다. 일반적인 저장 실패는 입력을 유지하지만 인증 만료에 의한 화면 교체에서는 보호되지 않습니다. 노래 편집기도 같은 로그인 이동 예외를 허용하며 별도 초안 복구가 없습니다.

- 근거: src/services/api.js:34, src/App.vue:18, src/pages/AdminScheduleImage.vue:20, src/pages/SongEditor.vue:27, src/schedule/useScheduleEditor.js:8.
- 수정 방향: 로그인 사용자·편집 대상별 브라우저 임시 보관과 재로그인 후 복원 확인. 다른 사용자에게 초안이 복원되지 않도록 구분하고 저장 성공 시 정리합니다. 자발적 로그아웃에는 미저장 내용 확인을 적용합니다. 서버의 수동 저장·권한 검사는 유지합니다.
- 회귀 검증: 일정·노래 편집 각각 입력 → 저장 중 401 → 재로그인 → 같은 편집 화면·초안 복구. 다른 계정으로는 복구하지 않음.

## R2. 날짜 입력 취소 후 표시 불일치

2027-01-04 주에서 내용을 입력하고 주 선택을 2027-02-01로 바꾼 뒤 이동 확인을 취소했습니다. URL과 주간 범위는 1월 4일인데 날짜 입력칸은 2월 1일로 남았습니다. 실제 저장 대상은 URL의 기존 주이므로 입력칸을 기준으로 판단하면 다른 주의 내용을 수정할 수 있습니다.

- 근거: src/pages/AdminScheduleImage.vue:19, :33. native date 입력값 변경 후 router 이동 취소 시 입력값을 기존 주로 되돌리는 처리가 없습니다.
- 수정 방향: 날짜 변경 승인과 화면 반영을 묶고, 취소·실패 시 날짜 입력을 실제 route의 주로 되돌립니다. 월/주 선택값도 같은 방식으로 점검합니다.
- 회귀 검증: 취소 후 입력값·URL·주간 범위·내보내기 파일명·저장 대상이 모두 기존 주와 동일.

## R3. 이미지 출력 잘림 방지

한 날짜에 12줄을 입력하면 글자 넘침 경고가 나오지만 PNG 출력은 그대로 진행됩니다. 실제 PNG에는 앞의 2줄만 표시됐습니다. 표시 영역 높이는 76px, 내용 높이는 380px이며 overflow hidden으로 잘립니다.

- 근거: src/components/schedule/ZioScheduleCanvas.vue:14, :127; src/components/schedule/ZioScheduleField.vue:96; src/schedule/exportImage.js:4. 출력 함수는 이미지·폰트 로딩만 기다리고 필드 넘침 상태를 확인하지 않습니다.
- 수정 방향: 넘친 날짜를 강조하고 다운로드 전에 명시적으로 확인하거나 조정을 요구합니다. 글자 자동 맞춤 또는 줄 수 안내를 선택적으로 제공합니다. 저장 가능한 500자 제한과 이미지에 실제 들어가는 길이는 구분해야 합니다.
- 회귀 검증: 기본 크기/최대 글자 크기/긴 시간 안내/여러 줄에서 경고·출력 정책 확인. 출력 규격과 PC·모바일 이미지 동일성은 유지합니다.

## R4. 배포 소스 보관

로컬 HEAD와 원격 codex/phase1은 모두 4a647518e99c3deb2bdf444dd8e9f60061192574입니다. 새 UI·일정 화면·공유 모듈·migration 0004 등이 수정 또는 미추적 상태입니다. 현재 Cloudflare 배포를 재현하는 소스가 이 GitHub 브랜치에는 기록되지 않았습니다.

- 수정 방향: 최근 실제 변경을 검토해 커밋·push하고 배포 버전과 연결합니다. 사용자 선행 SQL 조회문 수정, 참고 ZIP, 테스트 DB, 비밀값, SQL 백업은 따로 구분해 무조건 전체 추가하지 않습니다.
- 필요한 정리: 신규 파일 포함 여부 확인, 비밀값·SQL 백업 제외 확인, 실행 migration 추적, 재설치·빌드·배포 재현 방법 기록.

## R5. 선택한 주 유지

2027-01-04 주를 보는 중 일정 관리 메뉴의 현재 스케줄 이미지 탭을 다시 클릭하면 week 쿼리가 사라지고 분석일의 이번 주(2026-10-12)로 바뀌었습니다.

- 근거: src/components/schedule/ScheduleNav.vue:1. 이미지 탭 링크에 현재 week가 없습니다.
- 수정 방향: 현재 탭은 현재 주를 유지합니다. 달력과 이미지 화면을 오갈 때 선택 날짜·주·월을 전달하고, 이번 주로 이동은 별도 의도가 드러나는 버튼으로 제공합니다.

## R6. 로그인 후 원래 목적지 복귀

/admin/schedule/image?week=2027-01-04를 비로그인 상태에서 열고 로그인하면 /admin으로 이동했습니다. 원래 경로와 선택한 주가 전달되지 않습니다.

- 근거: src/router/index.js:70, src/pages/AdminLogin.vue:22.
- 수정 방향: 보호 경로에서 내부 복귀 경로를 보존하고 로그인 성공 시 이동합니다. 직접 로그인한 경우의 기존 관리자 관리 메뉴는 유지합니다. 외부 URL 또는 허용되지 않은 복귀 경로는 거부하고, 강제 비밀번호 변경을 우선합니다.

## R7. 저장 결과 표시

저장 요청에 503을 반환시키면 입력은 남지만 오류는 녹색 role=status 문구에 표시됩니다. 오류용 alert는 없었습니다. 미저장 주도 저장된 일정과 같아요라고 표시돼 신규·저장 완료 상태를 구분하기 어렵습니다.

- 근거: src/schedule/useScheduleEditor.js:26, src/pages/AdminScheduleImage.vue:33, :36.
- 수정 방향: 처리 중·성공·실패를 구분해 실패에는 눈에 띄는 오류 안내와 재시도 동작을 제공합니다. 아직 저장 안 된 주, 변경됨, 저장 완료, 마지막 저장 시각을 구분합니다.
- 관련 점검: src/App.vue:34의 공통 알림과 src/pages/AdminUsers.vue:87의 자체 알림이 각각 존재합니다. 알림 표시 위치·종료와 상태 관리를 통일하면 화면 간 중복을 줄일 수 있습니다. 중첩 알림은 이번에 브라우저로 재현하지 않고 코드상 개선 후보로 분리했습니다.

## R8. 편집 화면 사용성

현재는 주 선택 → 이미지 꾸미기 → 접힌 날짜별 입력 → 미리보기 순서입니다. 설정을 보면서 일정과 출력 결과를 함께 확인하려면 스크롤이 길고, 모바일에서 큰 입력창이 기본으로 접혀 있습니다.

- PC: 날짜별 입력과 미리보기를 좌우로 배치하거나 미리보기 고정 영역을 검토합니다.
- 모바일: 날짜별 입력을 우선 노출하고 글자·색상 같은 꾸미기 옵션은 필요할 때 펼치도록 배치합니다. 7열 달력 외에 주간/목록 보기도 검토할 수 있습니다.
- 문구: 서버에 저장 → 일정 저장, 서버에서 다시 불러오기 → 저장된 일정 불러오기처럼 사용 목적이 드러나는 표현으로 정리합니다.

## 추가로 점검할 후보

- 로그인 제한은 성공한 로그인도 IP/계정 카운터에 포함합니다(server/services/auth.js:35, :46). 실제 확장 브라우저 테스트에서도 정상 로그인 횟수가 누적돼 제한이 걸린 적이 있습니다. 보호를 제거하지 않고 정상 계정 전환과 실패 제한 정책을 함께 검토할 수 있습니다.
- 달력의 today는 화면 생성 시 한 번 계산됩니다(src/pages/AdminSchedule.vue:11). 자정을 넘겨 열린 화면에는 날짜 강조·이번 달 버튼 갱신이 필요할 수 있습니다. 이 항목은 코드 검토이며 이번에 시간 이동으로 재현하지 않았습니다.
- 한 줄로 압축된 신규 Vue/JS/CSS와 기존·신규 전역 스타일의 중복은 코드 포맷·스타일 역할 정리로 유지보수 부담을 줄일 수 있습니다.

## 분석 범위와 증거

- 운영: HTML 최종 빌드 일치, health/D1 ready, 익명 일정 API 401을 읽기 전용으로 확인.
- 재현: E2E 모드의 .local/e2e/state만 사용했습니다. 테스트 관리자와 초안을 사용했으며 운영 계정·일정·노래는 수정하지 않았습니다. 재현 서버는 종료했습니다.
- 기록: .local/improvement-review/findings.json, date-after-cancel.png, overflow-output.png.
- 이전 68개 테스트는 기본 기능·권한·출력 규격을 검증했습니다. 이번에 확인한 날짜 입력 직접 변경 후 취소, 현재 탭 재클릭, 401 후 초안 복구, 긴 글자 출력 정책 등의 시나리오를 회귀 테스트에 추가하는 것이 좋습니다.
