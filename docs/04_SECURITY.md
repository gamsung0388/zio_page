# 04. 보안·인증·운영 요구조건

## 관리자 계정 초기화
- **인증되지 않은 회원가입/관리자 생성 API 금지**. 추가 관리자 등록은 기존 관리자의 유효한 세션과 Origin/CSRF 검증 후에만 허용한다. 사용자 요청에 따라 관리자별 비밀번호 초기화와 본인 비밀번호 변경을 제공한다. 최초 관리자 계정 생성은 운영자 로컬 CLI 또는 안전한 D1 migration+별도 준비 과정에서만 수행.
- 사용자 ID와 비밀번호는 운영자가 직접 지정. 등록·변경·최초 생성 CLI의 비밀번호 길이는 사용자 요청에 따라 8~256자로 통일한다. 최초 계정의 기본/하드코딩 비밀번호 없음.
- 비밀번호는 높은 비용의 검증 가능한 패스워드 해싱 기법(PBKDF2-HMAC-SHA256 + 랜덤 salt + 충분한 iteration 등 WebCrypto Worker 환경에서 실제 지원 가능한 방식)을 사용. 암호학적 난수 사용, 상수시간 비교 고려. 단순 SHA-256 단독 해시 금지.
- 로그인 실패 rate limit/IP 기반 방어(Workers 무료 범위에서 가능한 단순 제한 + 일반화된 오류 메시지), 오류 시 계정 존재 여부 노출 금지.

## 세션
- 로그인 성공 시 CSPRNG 토큰을 발급하고 서버 DB에는 **토큰 해시만** 저장.
- Cookie: `HttpOnly; Secure; SameSite=Lax; Path=/;` (운영환경 HTTPS). 로컬 개발 테스트용 쿠키 처리는 구분.
- 로그아웃 시 DB 세션 제거, 만료 시간(예: 7일) 검증, 관리자 강제 로그아웃 가능 구조.
- POST/PATCH/DELETE에서 Origin/Referer allowlist와 SameSite를 함께 검증, 필요 시 CSRF 토큰 사용.
- 쿠키 세션 API에서 `Access-Control-Allow-Origin: *` 설정 금지. 동일 출처 우선.

## 권한·데이터
- 모든 DB 쓰기 API에서 관리자 인증 필수. UI 버튼 숨기기만으로 보호하지 않음.
- 공개 목록·상세는 SQL에서도 `is_public=1` 강제. 비공개 조회에 404 반환.
- 사용자 입력 검증, SQL 바인딩, 정렬 whitelist, 페이지 크기 상한, CSV formula injection 대비 내보내기 처리.
- `memo`는 공개 조회의 SELECT 목록에서 아예 제외.
- 설명은 기본 텍스트로 렌더링하고 HTML 직접 삽입(`v-html`) 금지.
- 에러 로그에 세션/암호/개인정보 남기지 않음.
- 최소 권한 Cloudflare API 토큰 사용, Secrets/GitHub 키 유출 금지.

## 운영 및 백업
- DB migration 버전 추적, 프로덕션 적용 전 로컬 테스트/백업.
- 관리 화면 CSV 다운로드 또는 Wrangler D1 export로 주기적인 별도 백업. CSV는 관리자 메모 포함 가능하므로 안전하게 보관.
- 무료 요청/DB 읽기·쓰기 한도 초과 시 서비스가 실패할 수 있으므로 사용량 감시 및 안내 문구 마련.
- 사용자 데이터 삭제/변경에 대한 감사 로그는 추후 기능으로 검토하되 인증 관련 이벤트는 안전하게 기록.

## 비밀번호 변경 및 초기화 (추가 요청 반영)
초기화 비밀번호는 사용자가 지정한 `qwer1234!@#$`이다. DB에는 난수 salt와 PBKDF2 해시만 저장하고 초기화 시 대상의 기존 세션을 전부 폐기한다. `must_change_password=1` 계정은 본인 비밀번호 변경·인증 상태 확인·로그아웃 외 관리 API를 서버에서 차단한다. 새 비밀번호는 초기화 비밀번호 및 현재 비밀번호와 달라야 한다. 정상 변경 시 모든 세션을 폐기하고 재로그인한다. 현재 비밀번호 검증은 계정별 요청 제한을 적용한다. 새 관리자도 동일한 관리 권한을 갖는다. [세부 계약](09_ADMIN_ACCOUNTS.md).

## 관리자 초안 임시 보관

일정 이미지·달력 날짜·노래 폼의 초안은 사용자 ID와 편집 대상별로 분리해 sessionStorage에 보관합니다. 자동 로그인이나 서버 저장을 대신하지 않습니다. 최대 24시간/초안 100,000자이며 손상·기한 만료·저장 거부 시 편집을 막지 않습니다. 비밀번호·쿠키·CSRF·API 키는 포함하지 않습니다. 비공개 노래 메모는 인증된 해당 계정의 편집 화면에서만 복구하며 공개 API/페이지에 전달하지 않습니다. 로그아웃 확인 후 해당 계정의 초안을 지웁니다. 동일 출처 스크립트가 접근 가능한 임시 저장이므로 공유 기기에서는 로그아웃하고 영구 백업을 별도로 관리합니다.

일정 초안은 원래 revision을 복구해 최신 저장과 충돌하면 409로 막습니다. 노래 초안은 저장 시각이 바뀌었으면 복구 전 확인합니다. 기존 노래 PATCH 계약에는 버전 조건이 없으며 이 점은 추가 개선 분석에 기록합니다.

로그인 제한은 검증 전에 원자적으로 예약하고 성공한 요청의 예약만 같은 만료 구간에서 1씩 차감합니다. 실패/동시 시도 제한은 유지하며 성공한 요청이 다른 실패 기록을 지우지 않습니다.
