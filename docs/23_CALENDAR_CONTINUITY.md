# 23. 기간 일정의 연속 표시

날짜마다 같은 제목의 카드가 반복되던 달력을 **한 주에 하나의 기간 막대**로 바꿨습니다. 주를 넘어가면 왼쪽·오른쪽 화살표와 같은 색·제목으로 이어짐을 표현합니다. 10월 17~30일 일정은 17~18일, 19~25일, 26~30일의 세 막대로 표시됩니다. 어느 막대를 눌러도 같은 저장된 일정의 수정창을 엽니다.

## 적용 범위

- 겹치는 기간 일정은 별도 줄에 배치하고, 가능한 경우 다음 주에도 같은 줄을 유지합니다.
- 하루 일정은 날짜 칸에 유지합니다. 주간 막대의 자리와 겹치지 않도록 아래쪽에 배치합니다.
- 날짜별로 최대 3개 일정을 표시합니다. 가려진 기간 일정과 하루 일정은 모두 더 보기 개수에 포함하고 해당 날짜의 목록에서 조회합니다.
- 실제 시작·종료 시간, 종일·시간 미정, 한국 날짜를 유지합니다. 자정 종료는 다음 날짜에 포함하지 않고 종일·시간 미정의 종료 날짜는 포함합니다.
- 기본 목록 보기, 날짜 선택 등록, 수정·삭제·백업·이미지 가져오기, 세션·권한 검사는 유지합니다.
- 운영 API·D1 스키마·Wrangler 설정·주소·의존성은 변경하지 않았습니다. 추가 migration이 없습니다.

## 검증

날짜·시간·주별 배치 단위 14개, 브라우저 23개로 총 **37개 항목**을 검증했습니다. 브라우저 범위는 새 연속 표시 4개와 기존 일정·페이지·목록 날짜·가이드 19개입니다. 실제 저장·수정·삭제 검증은 격리 테스트 DB만 사용합니다.

반응형 기준은 1920×1080, 1440×900, 768×1024, 390×844, 360×800입니다. 기간 막대끼리 겹치지 않고 날짜 버튼을 가리지 않는지, 주 경계 밖으로 나가지 않는지, 한 주 전체 막대가 실제 주 너비를 채우는지 확인했습니다. 시간대는 미국/로스앤젤레스에서도 한국 일정 날짜를 유지하도록 시험합니다. 프로덕션 빌드도 확인합니다.

변경 파일은 위 8개와 본 문서, README.md입니다. 기존 사용자의 `database/migrations/0001_initial.sql` 수정과 UI 참고 ZIP은 보존하고 커밋 대상에서 제외합니다. 요청한 연속 표시는 실제 API에 연결되어 있으며 별도 미연결 기능은 없습니다.

## 현재 주소를 바꾸는 방법

현재 주소 `zio-home.ryan9320.workers.dev`에서 `zio-home`은 Worker 이름이고 `ryan9320`은 계정의 workers.dev 이름입니다. 계정 이름은 **Workers & Pages → Your subdomain → Change**에서 변경합니다. 계정 공통 이름이므로 같은 계정의 다른 Workers 주소에도 영향을 줍니다. Worker 이름을 바꾸려면 대시보드의 실제 리소스와 프로젝트 설정을 함께 맞춰야 합니다. 프로젝트의 name만 임의로 바꿔 새 Worker에 배포하지 않도록 합니다. [Cloudflare 공식 안내](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/).

개인 도메인을 쓰려면 소유한 도메인을 Cloudflare의 활성 사이트로 연결한 뒤, **Workers & Pages → zio-home → Settings → Domains & Routes → Add → Custom Domain**에서 추가합니다. 대시보드 버전에 따라 Domains 탭에 표시될 수 있습니다. Cloudflare가 DNS와 인증서를 구성합니다. 이후 배포에서도 연결이 유지되도록 실제 설정을 확인해 Wrangler routes와 동기화합니다. 도메인 등록·갱신 비용은 별도입니다. [도메인 연결](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/) · [도메인 등록 서비스](https://developers.cloudflare.com/registrar/).

희망 주소가 지정되지 않았으므로 이번 작업에서 주소·DNS·Worker 이름은 변경하지 않았습니다.
